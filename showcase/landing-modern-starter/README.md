# Landing Modern Starter

Boilerplate de Landing Pages modernas, rápidas e com SEO técnico.

- Stack: HTML + CSS + JS (puro) • opcional: Tailwind/Next
- Estilo: minimal/futurista (inspirado em Apple/Vercel/Linear)
- Foco: conversão, Lighthouse 100/100, acessibilidade, SEO on-page

## Recursos
- Hero c/ gradiente, glass, typing effect (opcional)
- Seções: Proposta de Valor, Provas Sociais, Oferta/Preços, FAQ, CTA
- Metadados, Open Graph, JSON-LD (schema.org), favicon
- Estrutura modular para escalar p/ Next.js + Tailwind

## Como usar (estático)
1. Abra `template/index.html` no navegador
2. Edite conteúdo em `index.html` e estilos em `style.css`

## Próximo nível (Next.js + Tailwind)
- Migrar para Next/Vercel quando precisar de CMS/AB tests.
