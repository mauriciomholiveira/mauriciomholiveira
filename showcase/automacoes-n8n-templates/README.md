# Templates de Automações (n8n)

Coleção de workflows de automação para captação de leads, integração e notificações. Sem credenciais — prontos para importar no n8n.

## Templates
- `lead_to_sheet.json` — formulário → planilha (Google Sheets)
- `new_lead_notify_whatsapp.json` — lead → WhatsApp/Mailer
- `github_issue_to_trello.json` — GitHub Issue → Trello card

## Como usar
1) Abra seu n8n
2) Import > cole o JSON do template
3) Configure credenciais nas conexões
