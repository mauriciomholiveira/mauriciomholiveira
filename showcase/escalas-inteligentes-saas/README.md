# Escalas Inteligentes (SaaS Demo)

Demonstração conceitual de um app para gestão de turnos e calendário com regras simples e notificações (conceito). Foco em arquitetura e UX do produto.

## Conceitos
- Usuários (admins, gestores, colaboradores)
- Escalas por equipe, turnos e folgas
- Regras de conflito (sobreposição, carga máxima)
- Notificações (mock)

## Estrutura simples
- `data/sample.json` — exemplo de equipes/turnos
- `docs/arquitetura.md` — visão de módulos

## Próximos passos
- Converter em app real com React + backend (Node/Postgres)
- Implementar RBAC completo e calendário interativo
